# Mathankumar Portfolio (starter source)

This is a recreated starter project for your portfolio, not a download of the original private source code from your live Netlify deployment.

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP and open the folder in VS Code.
3. In the terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

## Before deploying
- In `src/App.tsx`, replace `your-email@example.com` with your public email address (in both places).
- Add your actual resume PDF as `public/resume.pdf`.
- Update skills and certification entries to match your real experience.
- Test every route and contact behavior before publishing.

## Routes
`/`, `/about`, `/skills`, `/learning-and-certifications`, `/resume`, `/contact`

The contact form uses a `mailto:` link, which opens the visitor's email app; it does not send messages directly from the website. For direct website submissions, configure Netlify Forms or a backend/form service.
